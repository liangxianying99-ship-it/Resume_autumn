# 秋招投递记录 — 独立 Chrome 插件

无需 Mac App、Python、本地服务、配对码或付费 API。不包含个人投递记录。

## 一次安装

1. 下载并解压插件文件夹，保存在 Mac 上一个固定位置，不要删除。
2. Chrome 地址栏输入 `chrome://extensions`，开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择包含 `manifest.json` 的插件文件夹。
4. 点击 Chrome 工具栏的拼图图标，将“秋招投递记录”固定到工具栏。

## 记录投递

- 点击插件 → “打开我的投递记录” → “导入表格”，选择现有 `.xlsx` 文件，支持原表格的投递时间、公司、岗位、岗位 JD、进度列。也可导入 UTF-8 CSV 或本插件导出的 JSON 备份。
- 重复导入内容完全一致的记录会跳过。修改后的表格行作为新记录导入，避免覆盖手动更新；此时可能出现重复岗位。
- 在岗位页点插件 → “采集当前岗位”，核对公司、岗位、JD 和进度，再保存。
- 如需自动捕捉，点击“启用当前网站自动监测”并授权本站。常见提交按钮先记录为“待确认”；之后检测到新的明确成功提示，才更新为“已投递”。可随时停用网站。
- 后续进度在记录页面编辑，支持搜索、导出 CSV、备份 JSON。

## 数据和范围

记录保存在当前 Chrome 配置的 `chrome.storage.local`，不上传云端；关闭浏览器后仍保留。卸载插件或清除扩展数据会删除记录，请先导出 JSON 备份。数据不会自动同步到另一台电脑或另一套 Chrome 配置。

通用规则可在任意授权的 HTTPS 招聘网站尝试使用，但不保证所有公司页面准确识别。复杂列表、跨域申请、iframe、非标准按钮等可能需要手动采集。公司字段缺乏规范数据时可能显示网站域名。JD 可能包含页面其他可见文字，保存前请核对。不会读取密码、上传的简历附件或邮件，不会后台自动登录招聘网站。面试、拒绝、Offer 等后续状态仍需手动编辑。

表格读取完全在本机进行，不使用外部解析服务。仅支持未加密 `.xlsx`、CSV、JSON，不支持旧 `.xls`；有多工作表时读取第一个工作表。表格最大 20MB、单次最多 10000 条有效记录。只读取单元格已有值，不执行公式或表格中的文字指令。

本版本不在 Chrome 应用商店中，因此需要上述开发者模式安装。

## 验证范围

JavaScript 语法检查通过。实际 UI、表格解析与后台存储逻辑在 Chromium 中用模拟 Chrome API 接口测试，覆盖原始 XLSX 8 条记录导入、去重、完整 JD、手动新增、投递事件更新、导出和浏览器重启持久化。云端 Chromium 管理策略禁止加载未打包扩展，未完成真实安装及招聘网站端到端验证。
